Clinical Safety Logic

RetinaGuard Safety Gate

The system asks whether the prediction is safe to trust or should be reviewed manually.

Uncertainty

Uses confidence, entropy, and top-2 probability margin.

Image Quality

Checks blur, brightness, and contrast before trusting the prediction.

Lesion Evidence

Uses U-Net lesion burden and consistency with predicted DR grade.

Triage Decision

Returns safe negative, follow-up, referral, urgent referral, or manual review.
