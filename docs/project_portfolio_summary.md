# RetinaGuard-AI Portfolio Summary

Title:
RetinaGuard-AI: Explainable and Safety-Aware Diabetic Retinopathy Screening Pipeline

One-line description:
An end-to-end medical AI research project for diabetic retinopathy grading, lesion segmentation, lesion feature analysis, late fusion, explainability, safety triage, and API deployment.

Key technologies:
- PyTorch
- EfficientNet-B0
- U-Net ResNet34
- Albumentations
- Scikit-learn
- OpenCV
- FastAPI
- Medical image analysis

Best results:
- EfficientNet-B0 APTOS test QWK: 0.8899
- Probability-only meta-classifier APTOS test QWK: 0.8965
- U-Net tuned-threshold IDRiD test mean Dice: 0.4831
- Lesion area vs DR grade Spearman correlation: 0.7661

Why this project is strong:
Most projects stop at classification. RetinaGuard-AI includes classification, segmentation, feature validation, fusion, explainability, safety triage, deployment, and documentation.
